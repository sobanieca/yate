yate - yet another text editor

Usage:
  yate                  open the current folder (file tree)
  yate <folder>         open a folder
  yate <file>[:line]    open a file; the project is its git repository
  yate update           install the latest release (./update opens a file named update)

Options:
  -h, --help            show this help
  -v, --version         show the version

Keys (VS Code style, no modes; ctrl+h in yate lists every binding):
  ctrl+h                key bindings (search them, enter runs one)
  ctrl+p                find file (fuzzy)          alt+f    live grep
  ctrl+f in a picker    glob filter: *.ts, src/**, !*.test.ts (! excludes; kept for the
                        next search)
  alt+r                 resume last picker
  alt+p                 command palette: what the focused panel (editor or file tree) can
                        do right now, by section (File, Edit, Search, Go to...)
  alt+w                 then 1 file tree, 2-9 recent files (they pop up when you wait);
                        alt+w again: next recent file, alt+shift+w: previous
  alt+e                 toggle file tree           ctrl+t   reveal file in tree
  alt+s                 split: then 1 vertical (side by side), 2 horizontal (one above
                        the other), 3 resize the pane (type columns,rows to add: 10, -10
                        or 10,-2), 4 equal sizes, 5 close the pane, 6 close the others
  alt+h / j / k / l     focus the pane on the left / below / above / on the right
  ctrl+o                next pane                  ctrl+j   scroll all panes together
  ctrl+s                save                       ctrl+n   new file
  ctrl+q                quit
  alt+left / alt+right  jump back / forward
  ctrl+g                go to: then 1 a line, 2 the definition, or the file of the path or
                        import under the cursor (also ctrl+click; path:line:col works;
                        ctrl+p takes file:line)
  ctrl+f / ctrl+r       find / replace in file     enter, down / up  next / previous match
  ctrl+z / ctrl+y       undo / redo                ctrl+a   select all
  ctrl+c / ctrl+x       copy / cut (line without a selection; tmux buffer)
  ctrl+v                paste (newest tmux buffer inside tmux)
  ctrl+d                select word / next occurrence
  ctrl+/                toggle comment             ctrl+k   delete line
  alt+up / alt+down     move line                  alt+shift+down  duplicate line
  tab / shift+tab       indent / outdent           alt+i / alt+o   the same
  ctrl+left / right     10 characters (jumpChars)  ctrl+up / down  5 lines (jumpLines)
  alt+m                 bookmarks: then 1 toggle, 2 next, 3 previous, 4 list, 5 clear

Every command has one key; ctrl+g, alt+m and alt+s pop up a numbered menu (digit, or arrows and
enter; esc closes). No key needs ctrl+shift.

No tabs: the editor shows one file (one per pane in a split). Opening a file takes the place of the
one shown; unsaved changes ask first (s save, d discard, esc stay). A file opens again
where the cursor was, and ctrl+p lists the files you had last on top.

File tree: enter open, left/right fold, f find file in the folder, g live grep in the
           folder, ctrl+n new, r rename, d delete, y copy path, i show ignored files,
           m only changed files, shift+r refresh, [ narrower, ] wider (or drag the right
           edge; "treeWidth" in options keeps a width), esc editor.

Settings: ~/yate.json, overridden by yate.json files closer to the working directory
          (theme, options, keys, plugins); yate.jsonc works too. "Open yate.json" in
          the palette creates ~/yate.jsonc listing every key binding, ready to edit.
Plugins:  ~/.config/yate/plugins/<name>.js (JavaScript), loaded when yate.json has
          "plugins": { "<name>": true }.
Log:      ~/.local/state/yate/yate.log
Updates:  checked once a day; "updateCheck": false in options or YATE_NO_UPDATE_CHECK=1
          turns the check off.
